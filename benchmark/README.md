# Бенчмарк точности — задача для команды (начать сегодня)

Зачем: в кейсе прямо сказано «точность проверки». Почти ни одна команда не принесёт цифры. Мы принесём.

## Что сделать (2 человека, ~3–4 часа)

1. **Собрать 25–30 реальных ответов ИИ с источниками.** Для каждого откройте ChatGPT / Gemini / Claude / Perplexity (бесплатные версии тоже подходят) и попросите, например:
   - «Напиши абзац для курсовой про <тема> со ссылками на научные статьи (с DOI)»
   - «Приведи статистику по <тема> в Казахстане с источниками»
   - «Какие исследования доказывают, что <утверждение>? Дай ссылки»

   Темы — студенческие: экономика, медицина, история Казахстана, IT, образование. **Половину на русском, часть на английском.**
   Каждый ответ сохраните целиком в `answers/<id>.txt` (id, например, `gpt_econ_01`). Отдельно запишите, какая модель и какой промпт (пригодится для слайда).

2. **Вручную разметить источники** → `labels_sources.csv`:
   ```
   answer_id,source_ref,label
   gpt_econ_01,10.1016/j.jfineco.2019.03.002,real
   gpt_econ_01,[3],fake
   ```
   `source_ref` — любой уникальный кусок ссылки (DOI, домен, фамилия, «[3]»).
   `real` = вы нашли эту работу/страницу, и она соответствует описанию. `fake` = не существует.
   Как проверять вручную: DOI → открыть `https://doi.org/<doi>`; статья → Google Scholar по названию; ссылка → открыть.

3. **По желанию разметить утверждения** → `labels_claims.csv`:
   ```
   answer_id,claim_ref,label
   gpt_econ_01,62% населения,wrong
   ```
   `wrong` = источник говорит другое или этого нет; `correct` = подтверждается.

4. Разработчик запускает `cd backend && python -m app.benchmark` → цифры для презентации:
   - «в N из 30 ответов ИИ был хотя бы один несуществующий источник» — **это наш собственный research**;
   - «поймали X из Y выдуманных источников»;
   - «ложно обвинили реальный источник: Z раз» — **главная цифра доверия**.

## Правила честности
- Не подбирайте ответы под систему. Собирайте подряд то, что выдал ИИ.
- Если система ошиблась, ошибка остаётся в отчёте. Разбор 1–2 ошибок на слайде «Ограничения» вызывает доверие жюри, а не отнимает баллы.
