# Пруф — проверка ответов ИИ по источникам

Вставляешь ответ ChatGPT / Gemini / Claude → для каждого утверждения видишь **дословную цитату из реального источника** или честное объяснение, что с ним не так:

| Вердикт | Что значит | Как решаем |
|---|---|---|
| 🔴 Источник не существует | DOI не зарегистрирован, домена нет, страница 404, статьи нет ни в Crossref, ни в OpenAlex | **Детерминированно**, без LLM |
| 🟠 Источник говорит другое | Другие числа, перепутанные данные, более узкий вывод | LLM-судья **+ проверенная цитата** + программное сравнение чисел |
| 🟡 В источнике этого нет | Источник прочитан целиком, утверждения там нет | LLM-судья по полному тексту |
| ⚪ Не удалось проверить | Пейвол, защита от ботов, есть только аннотация | Честный отказ вместо догадки |
| 🟢 Подтверждено | Найдена дословная цитата | Цитата сверена с текстом источника |

Если ИИ не дал источника, включается **режим атаки**: поиск ищет не только подтверждения, но и опровержения (другая цифра, устаревшие данные, «миф»).

## Быстрый старт (локально, macOS)

```bash
# 1. backend
cd backend
python3 -m venv .venv && source .venv/bin/activate
pip install -r requirements-dev.txt
cp ../.env.example ../.env        # впиши LLM_API_KEY (и по желанию TAVILY_API_KEY)
python -m pytest -q               # 25 тестов, сеть не нужна

# 2. frontend (Angular 20)
cd ../frontend && npm ci && npx ng build   # собирается прямо в backend/static

# 3. запуск: всё на одном порту
cd ../backend && uvicorn app.main:app --reload --port 8000
# → http://localhost:8000
```

Во время разработки UI: `make api` в одном терминале и `make web` в другом (Angular на :4200 проксирует `/api` на :8000).

### Демо-примеры должны открываться мгновенно

```bash
cd backend && python -m app.prewarm
```

Скрипт прогоняет примеры из `backend/examples.json` **через настоящий пайплайн** и сохраняет результаты в `backend/seed_cache/`. **Закоммить эту папку**: на сервере при старте она копируется в кэш, и примеры открываются без ожидания даже на бесплатном хостинге. В интерфейсе такой отчёт помечен как «сохранённая проверка». Это честный повтор реального прогона, а не подделка. После изменения пайплайна или примеров запусти скрипт заново.

## Деплой (Render, бесплатно, один URL)

1. Запушь репозиторий на GitHub.
2. Render → New → Blueprint → выбери репозиторий (`render.yaml` уже есть; сборка идёт по `Dockerfile`).
3. В Environment задай `LLM_API_KEY` (+ `LLM_PROVIDER`/`LLM_MODEL`, `TAVILY_API_KEY`, `CONTACT_EMAIL`).
4. Проверь `https://<app>.onrender.com/api/health` → `"llm_configured": true`.

⚠️ Бесплатный Render засыпает через 15 минут простоя, первый запрос после этого идёт ~30–60 с. **Разбуди сервер перед тем, как жюри откроет ссылку**, а лучше поставь бесплатный пинг раз в 10 минут (UptimeRobot / cron-job.org на `/api/health`).

Подойдёт любой хостинг Docker-контейнеров (Railway, Fly.io).

### Какую модель брать
- **Groq** (`LLM_PROVIDER=groq`, бесплатный лимит, очень быстро): `llama-3.3-70b-versatile`.
- **OpenAI** (`LLM_PROVIDER=openai`): дешёвая mini-модель.
- **Anthropic** (`LLM_PROVIDER=anthropic`): `claude-haiku-4-5`.

Названия моделей меняются, поэтому сверься с документацией провайдера. Модель задаётся через `LLM_MODEL`.

## Архитектура

```
Angular (signals, SSE) ──POST /api/check──▶ FastAPI ──▶ job (asyncio) ──▶ события по SSE
                                              │
  1. extract.py   LLM → утверждения + источники (JSON) + regex-страховка для URL/DOI
  2. sources.py   doi.org handle API → Crossref / OpenAlex → HTTP (SSRF-safe)   ← БЕЗ LLM
                  текст: страница (trafilatura) / открытый PDF / аннотация
  3. textutil.py  чанки → BM25 по стеммам (ru/en) + бонус за совпадающие числа
  4. judge.py     LLM-судья обязан вернуть ДОСЛОВНУЮ цитату → код ищет её в источнике
                  (rapidfuzz ≥ 90 + все числа цитаты должны быть в источнике), иначе вердикт отброшен
                  + детерминированное сравнение чисел утверждения и источника
  5. search.py    нет источника → Tavily (или Википедия) по нейтральному и 2 «атакующим» запросам
  6. store.py     стриминг событий, кэш по хэшу текста, отчёты по ссылке /r/<id>
```

Ключевые решения:
- **FastAPI, а не Django**: весь пайплайн — это параллельный сетевой I/O (десятки запросов на проверку) и стриминг. БД не нужна.
- **Без векторной БД и эмбеддингов**: источники короткие, BM25 по стеммам + числа работает на ru/en/kk без лишнего API.
- **Существование источника никогда не решает LLM.** Пейвол/403 → «нет доступа», а не «фейк». Ложное обвинение реального источника — худшая ошибка для такого продукта.
- **Проверка собственного ИИ**: цитата, которой нет в тексте, или цитата с изменённым числом отбрасывается (см. `test_fabricated_quote_from_judge_is_dropped`).
- **Безопасность**: SSRF-защита на каждом редиректе, лимиты размера/таймауты, rate limit, текст источника передаётся судье как данные.

## Точность: бенчмарк

См. `benchmark/README.md`. `python -m app.benchmark` считает: сколько выдуманных источников поймали, **сколько раз ложно обвинили реальный источник**, точность вердиктов по утверждениям. Эти цифры идут на слайд.

## Ограничения (честно)
- Проверяем проверяемое: факты, числа, источники. Мнения, советы, код и рассуждения — нет.
- Книги и статьи без DOI/ссылки вне научных баз → «не проверить», а не «фейк».
- Страницы, которые рисуются только JavaScript, не читаются.
- Судья — LLM; мы ограничиваем его цитатами, но ошибки «разве это одно и то же» возможны. Поэтому цитата всегда показывается пользователю.
